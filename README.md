# Сладкий мост — MVP маркетплейса Якутия ⇄ Донбасс

Веб-приложение для межрегионального заказа кондитерских изделий со **сборными отправками («волнами»)**.
Кейс хакатона PEAK IT 2026, продвинутый уровень: работающее веб-приложение с серверной частью.
Дизайн — по макетам Figma «Сладкий мост» (десктоп 1440 и мобильная версия 390).

## Запуск

```bash
npm start          # http://localhost:3000, Node.js ≥ 18, без внешних зависимостей
npm test           # unit-тесты логики волн и тарифов
```

Переменные окружения: `PORT`, `ADMIN_PASSWORD` (по умолчанию `admin`), `DB_FILE` (по умолчанию `data/db.json`),
`TODAY=2026-12-10` — подменить «сегодня», чтобы показать сезонные правила (зима/лето/межсезонье).

**Демо без сервера.** Папку `public/` можно выложить на любой статический хостинг (GitHub Pages и т. п.):
если API недоступно, приложение само переходит в демо-режим — тот же код логики выполняется в браузере,
данные хранятся в `localStorage`. Дату можно подменить параметром `?today=2026-07-01`.

Демо-доступы: покупатель — телефон `+7 (914) 123-45-67`; администратор — `#/admin`, пароль `admin`.

## Что реализовано (раздел 5 кейса)

| Требование | Где |
|---|---|
| Двусторонний каталог, витрины «Сладости Якутии» / «Сладости Донбасса», карточки, фильтры, поиск, корзина | `#/catalog`, `#/product/:id`, `#/cart` |
| Сборные отправки: дата ближайшей отправки, срок окончания приёма, заполненность партии | `#/checkout/wave`, главная, `#/delivery` |
| Расчёт доставки от веса заказа и заполнения партии | `#/checkout/calc`, калькулятор на `#/delivery` |
| Отслеживание: принят → в сборке → в пути → на пункте выдачи → получен | `#/orders`, `#/orders/:id` |
| Подарочный сценарий: получатель в другом регионе, открытка, подпись, сюрприз | `#/gift`, шаг «Оформление» |
| Кабинет администратора: товары, волны, статусы заказов | `#/admin` |
| Оплата — имитация (заглушка) | шаг «Оформление» |

Дополнительно (раздел 6): сезонные предупреждения и термоупаковка, **дашборд встречной загрузки** обоих направлений,
аналитика (популярные товары, средний чек, прогноз объёма следующей волны), корпоративные (B2B) заказы, избранное.

Сценарии: «заказ себе» — каталог → корзина → волна → расчёт → оформление → отслеживание;
«подарок в другой регион» — `#/gift` → регион получателя → сладости → открытка → оформление.

## Логика волн и расчёт доставки

Всё в одном модуле `public/shared/logic.js` (используется и сервером, и браузером):

- Волны идут **раз в 14 дней в каждом направлении** (Якутия → Донбасс со 20.10.2026, Донбасс → Якутия с 27.10.2026),
  приём заказов закрывается **за 3 дня** до отправки, срок доставки **10–14 дней**.
- Тариф за кг считается по загрузке партии **вместе с заказом покупателя**:
  до 50 % (150 кг) — 500 ₽/кг; более 50 % — 400 ₽/кг (−20 %); более 80 % (240 кг) — 325 ₽/кг (−35 %). Максимум партии — 300 кг.
- **Доставка = тарифицируемый вес × тариф**, где вес = масса нетто × 1,1 (упаковка), минимум 0,5 кг.
- При закрытии сбора администратор фиксирует загрузку; доставка всех заказов волны пересчитывается по итоговому тарифу.
  **Цена может только снизиться** — разница возвращается.
- Партия не набрала 50 кг → статус «Перенесена», заказы автоматически переходят в следующую волну направления.
- Сезонность (по месяцу отправки и прибытия): декабрь–февраль и июнь–август — обязательная термоупаковка шоколадных изделий
  (+150 ₽ за заказ); май и ноябрь — межсезонье на Лене, срок доставки +7 дней; в остальное время термоупаковка по желанию.
- Статусы волны управляют статусами заказов: «Сбор закрыт» → «В сборке», «В пути» → «В пути», «Прибыла» → «На пункте выдачи».

### Допущения
- В одну отправку входят сладости **одного региона**: они едут из региона производителя к получателю в другой регион.
  Если в корзине товары обоих регионов, оформляются две отправки.
- Упаковка +10 % к весу; минимальный тарифицируемый вес 0,5 кг; пункт выдачи — бесплатно, курьер — 150 ₽.
- Каталог ДНР и производители — условные; фото — из макета Figma.
- В прошлых и текущих волнах есть условная загрузка «от других покупателей», чтобы демонстрировать скидки.

## Бизнес-модель
Комиссия 15 % с продажи товаров; подарочное оформление (коробка с открыткой, 250 ₽); термоупаковка (150 ₽);
корпоративные наборы (B2B). Доставка продаётся по себестоимости доли в партии — это конкурентное преимущество.

## Структура
```
server.js                 HTTP-сервер: REST API + статика, хранение в JSON-файле
public/shared/logic.js    волны, тарифы, сезонность (общий модуль)
public/shared/store.js    операции с данными: заказы, волны, товары, аналитика
public/shared/router.js   маршруты API (/api/...)
public/shared/catalog.js  демо-каталог по структуре приложения А
public/js/                SPA: витрина, оформление, кабинет, админка
tests/                    node:test
```

API: `GET /api/products`, `GET /api/waves?direction=&upcoming=1`, `POST /api/quote`, `POST /api/orders`,
`GET /api/orders?phone=`, `GET /api/orders/:id`, `POST /api/orders/:id/cancel`;
админ (`X-Admin-Token`): `GET /api/admin/stats|orders|waves|products`, `POST /api/admin/waves/:id/status`,
`POST /api/admin/orders/:id/status`, `POST|DELETE /api/admin/products`.
